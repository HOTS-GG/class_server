AI 채점 설정 (OpenRouter)

서술형 문항만 AI가 채점 초안을 만듭니다. 객관식·단답형은 AI를 쓰지 않습니다. API 키는 세이브 파일이 아니라 이 교사 PC의 프로필 폴더에 저장되어 세이브를 복사·공유해도 함께 나가지 않고, 학생 프로그램에는 전달되지 않습니다. AI에는 문항·채점기준·모범답안·학생 답안만 보내고 이름·번호 등 개인정보는 보내지 않습니다. 교사가 직접 채점한 답안이 있으면 같은 문항의 다음 채점에 예시로 붙여 기준을 맞춥니다.

화면

교사 화면에만 적용됩니다. 학생 프로그램은 각자 화면 위쪽에서 조절할 수 있습니다.

학생 화면 잠금 해제

시험 중 학생 프로그램은 임의로 종료할 수 없습니다. 특정 학생만 풀어주려면 해제 코드를 발급해 불러주세요.

세이브 파일

세이브 파일에는 학생 명단·과목·과제·시험·채점 결과·설정이 들어 있습니다(AI 키는 제외). 첨부 파일은 같은 위치의 이름.files 폴더에 저장되므로 옮길 때 함께 복사하세요.

자동 백업

시험 시작·종료 때와 하루 한 번 자동으로 이름.files\backups\에 사본을 남깁니다(최근 20개). 세이브가 깨지면 시작 화면의 [복구]로 되돌릴 수 있습니다.
