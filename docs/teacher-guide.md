# 교사용 사용설명서

## 1. 시작하기

1. 교사 PC에서 **교실 평가 시스템 (교사용)** 을 실행합니다.
2. 처음 실행 시 Windows 방화벽 창이 뜨면 **"개인 네트워크"에 체크하고 [액세스 허용]** 을 누르세요. (이걸 놓치면 학생이 접속할 수 없습니다 → [network-setup.md](network-setup.md))
3. 화면 상단에 **학생 접속 주소**(예: `192.168.0.10:3690`)가 표시됩니다. 칠판에 적어주세요.
4. 오른쪽 위 🌙/☀️ 버튼으로 라이트·다크 테마를, 🔍 화면 크기(90~150%)로 글자·버튼 크기를 바꿀 수 있습니다. (교사·학생 프로그램 동일, 각자 PC에 저장)
5. 탭 오른쪽의 **과목/학급** 선택으로 시험·과제 목록을 과목별로 나눠 봅니다. **[관리]** 에서 과목을 추가·이름 변경·삭제합니다. 저장 파일은 하나이고 학생 명단은 모든 과목에 공통입니다. 과목을 삭제해도 시험·과제는 "과목 없음"으로 남습니다.

## 2. 학생 명단 등록

- **[학생 명단] 탭** → 직접 추가하거나, **CSV 불러오기**(형식: `번호,이름` — 엑셀에서 저장한 파일 그대로 가능)
- 학생마다 **접속 코드 6자리**가 자동 발급됩니다. **[접속코드표 다운로드]** 로 출력해서 나눠주세요. 명단에서 코드를 누르면 화면 가득 크게 보여줄 수 있습니다.
- 출석번호는 1~999 사이의 정수만 등록되며, 같은 번호는 중복 등록되지 않습니다.
- 코드가 유출되면 해당 학생의 **[재발급]** 을 누르면 됩니다.

## 3. 학생 접속

학생 PC에서 `ClassServer-학생용.exe` 실행 →
**[자동 찾기]** (또는 칠판의 주소 입력) → 자기 접속 코드 입력 → 접속.
현황판에서 접속 여부가 실시간으로 보입니다.

## 4. 과제 배부와 회수

1. **[과제] 탭** → 제목/설명 입력, 파일 첨부 → **[과제 생성]**
2. 목록에서 **[배부]** 를 누르면 학생 화면에 나타납니다.
3. 학생은 파일을 내려받아(바탕화면 `받은과제` 폴더) 작업 후 **[제출하기]** 로 올립니다.
4. **[제출 현황]** 에서 실시간 확인, **[제출물 전체 다운로드 (zip)]** 로 일괄 회수 — `01_김민준/보고서.hwp` 형태로 정리됩니다.
5. **[삭제]** 는 배부 파일과 학생 제출물까지 함께 지우므로 필요하면 zip을 먼저 내려받으세요. 과제는 만들 때 선택된 과목에 속합니다.

## 5. CBT 시험

### 5-1. 문제 만들기

두 가지 방법이 있습니다.

- **직접 입력**: [시험] 탭 → **새 시험 만들기** → 객관식/단답형/서술형 문항 추가, 배점·정답 지정
- **엑셀로 일괄 등록**: **[문제 양식(엑셀) 다운로드]** 로 양식을 받아 문제를 채운 뒤 **[엑셀로 문제 가져오기]** → 편집기에서 검토 후 저장
  - 양식 열: `유형 | 문제 | 배점 | 정답 | 모범답안 | 채점기준 | 파일첨부 | 보기1 ~ 보기10`
  - 객관식 정답 = 보기 번호(1~N), 단답형 정답 = 인정 답안(여러 개면 `;`로 구분), 서술형은 정답 비움
  - **모범답안 · 채점기준**(서술형 전용): AI 채점의 근거입니다. 채점기준은 줄마다 한 항목씩 `항목 (n점)` 형태로 쓰면 AI가 항목별로 채점합니다. 항목 점수의 합이 배점과 같아야 합니다.
  - **파일첨부**(서술형 전용): `예`로 두면 학생이 답안에 파일(PDF · PNG/JPG/WEBP · TXT/MD, 10MB 이하)을 첨부할 수 있습니다.
  - 잘못된 행은 행 번호와 함께 알려주고 건너뜁니다. 양식 파일의 `작성안내` 시트에도 같은 설명이 있습니다.

문항 유형별 채점 방식:

| 유형 | 채점 | AI 사용 |
|---|---|---|
| 객관식 | 정답 보기와 비교해 자동 채점 | ✕ |
| 단답형 | 인정 답안과 비교해 자동 채점 (공백·대소문자 무시), 감독 화면에서 수동 정정 가능 | ✕ |
| 서술형 | AI가 채점 **초안**을 만들고 교사가 검토 후 반영 (직접 채점도 가능) | ○ |

- **문항 순서 섞기 / 선택지 순서 섞기**가 기본 켜짐 → 학생마다 문항 번호가 다르게 재구성되어 출제됩니다. (옆자리 훔쳐보기 방지)
- **종료 즉시 성적 공개**를 켜면 시험이 끝나는 순간 객관식·단답형 점수가 학생에게 바로 보입니다. 서술형은 채점되는 대로 학생 화면이 자동 갱신됩니다.

### 5-2. 시험 진행

1. **[시작]** → 시험 시간(분) 입력 → **전체화면 잠금 여부 선택** → 접속한 모든 학생 화면이 시험 모드로 전환됩니다.
   - 전체화면 잠금은 선택 사항입니다(기본 꺼짐). 잠금을 꺼도 붙여넣기 차단과 이탈 감지는 동일하게 작동합니다.
   - 학생 화면은 문제 영역과 **답안 표기란(OMR)** 이 분리되어 있어, 실제 CBT처럼 오른쪽 표기란에서 답을 고르거나 확인할 수 있습니다.
   - 파일 첨부가 허용된 서술형 문항에는 **[파일 첨부]** 칸이 생깁니다. 텍스트와 파일을 함께 제출할 수 있고, 다시 올리면 교체됩니다.
2. 감독 화면에서 학생별 **진행률 / 이탈 횟수 / 제출 여부**를 실시간 확인.
   - 학생이 다른 창으로 전환하면 즉시 표시됩니다. (⚠ Alt+Tab 자체를 막을 수는 없고, **감지·기록**됩니다)
   - 붙여넣기·복사 시도, 클립보드 변화도 모두 기록됩니다.
3. 시간이 끝나면 **자동 제출**됩니다. 먼저 끝낸 학생은 직접 제출할 수 있습니다.

### 5-3. 채점

객관식·단답형은 제출 즉시 자동 채점됩니다. 서술형은 아래 순서로 채점합니다.

1. **(처음 한 번) [도구 · 설정] 탭 → AI 채점 설정**에 OpenRouter API 키를 저장하고 **[연결 테스트]** 로 확인합니다. 채점 모델은 목록에서 고르거나 직접 입력할 수 있습니다.
2. 시험이 종료되면 감독 화면에 **[🤖 AI 채점 실행 (서술형)]** 버튼이 나타납니다. 누르면 제출된 서술형 답안이 채점기준·모범답안과 함께 AI에 전달되고, 진행률이 표시됩니다.
   - AI에는 **문항·채점기준·모범답안·학생 답안(첨부 파일 포함)** 만 보냅니다. 학생 이름·번호는 보내지 않습니다.
   - 첨부 파일이 있으면 AI가 내용을 요약하고 그것까지 포함해 채점합니다.
   - 이때 교사 PC에 인터넷 연결이 필요합니다. (시험 중에는 LAN만 있으면 됩니다)
3. 감독 화면의 **AI 채점** 열에서 학생별 상태를 봅니다.
   - `AI 2/2` 채점 완료 · `반영 n` 최종 점수에 반영됨 · `검토 n` AI 확신도가 낮아 직접 확인이 필요한 답안 · `오류 n` 채점 실패(재채점 필요)
4. **[답안/채점]** 을 열면 문항마다 AI 초안(점수 · 항목별 근거 · 확신도 · 피드백 제안)이 보입니다.
   - **[이 점수 적용]** 을 누르면 AI 점수와 피드백이 입력칸에 채워집니다. 고쳐서 **[채점 저장]** 하세요.
   - **[🤖 이 학생 AI 채점]** 으로 한 학생만 다시 채점할 수 있습니다.
   - "학생에게 보낼 피드백" 칸의 내용은 성적 공개 시 학생 화면에 그대로 표시됩니다.
5. 전체를 한 번에 반영하려면 **[AI 점수 전체 반영]** 을 누릅니다. **교사가 이미 직접 입력한 점수는 덮어쓰지 않습니다.**
6. **AI 점수는 초안입니다.** 반영 전까지 총점에 들어가지 않으며, 반영 후에도 언제든 학생별로 수정할 수 있습니다.

> ⚠ **종이 답안은 지원하지 않습니다.** 손글씨를 촬영·스캔한 파일은 글자 인식이 부정확해 AI 채점 결과를 신뢰할 수 없습니다. 답안은 반드시 컴퓨터로 작성(또는 컴퓨터로 만든 파일 첨부)하도록 안내하세요.

### 5-4. 결과 확인과 돌려주기

- **[결과 엑셀 다운로드]** → `점수` 시트(학생별 점수·문항별 점수·정답률), `서술형 상세` 시트(학생 답안·첨부 파일명·AI 점수·항목별 근거·확정 점수·피드백), `문항` 시트. **[CSV]** 도 됩니다.
- **성적 돌려주기**: 감독 화면에서 **[성적 공개]** 를 누르면, 학생들이 홈 화면의 [시험 결과]에서 본인 점수와 문항별 정오·정답·**피드백**을 확인할 수 있습니다. 언제든 **[성적 공개 취소]** 로 다시 감출 수 있습니다.
  - 공개 후에 서술형을 채점하면 학생 화면이 자동으로 갱신됩니다. 아직 채점되지 않은 서술형은 학생에게 "채점 중"으로 보입니다.
  - 학생에게는 정답과 피드백만 보이고, 모범답안·채점기준·AI의 원본 판정은 보이지 않습니다.
- **시험 관리**:
  - **복제** — 같은 문제로 재시험을 보고 싶을 때. 새 초안이 만들어지며 기존 시험과 결과는 그대로 보존됩니다.
  - **삭제** — 초안·종료된 시험 삭제 가능(진행 중은 불가). 종료된 시험은 학생 응시 기록·첨부 파일도 함께 삭제되니, 필요하면 결과 엑셀을 먼저 내려받으세요.
  - **수정** — 초안 상태의 시험만 수정할 수 있습니다. 종료된 시험을 고쳐서 다시 보려면 [복제] 후 수정하세요.

## 6. 시험 중 학생 프로그램 잠금

- 시험 중 학생은 프로그램을 종료할 수 없습니다.
- 특정 학생만 풀어줘야 하면: **[도구 · 설정] 탭 → 해제 코드 발급** → 코드를 불러주면 학생이 입력 후 종료 가능 (10분 유효, 1회용)
- 수업이 끝나면: **[전체 학생 잠금 해제]**

## 7. AI 채점 설정 상세

- **API 키**: [OpenRouter](https://openrouter.ai) 에서 발급. 교사 PC의 데이터 폴더(`db.json`)에만 저장되며 학생 프로그램이나 다른 곳으로 전송되지 않습니다. 화면에는 앞 8자·뒤 4자만 표시됩니다.
- **채점 모델**: 기본은 Claude Haiku 4.5(빠르고 저렴). 정확도를 높이려면 Claude Sonnet 4.5나 GPT-5 등으로 바꾸세요. **[🔄 목록 동기화]** 를 누르면 OpenRouter의 현재 모델 목록을 최신순으로 받아와 제공사별로 고를 수 있고, 검색칸으로 거를 수 있습니다(★ 표시는 추천 모델). 선택하면 컨텍스트 길이·가격·이미지/PDF 지원 여부가 아래에 표시됩니다. 목록에 없는 모델은 "직접 입력"으로 OpenRouter 모델 ID를 적으면 됩니다.
- **PDF 첨부 처리**: 기본 `텍스트 PDF`는 무료입니다. 이미지로만 된 PDF를 읽어야 하면 `OCR 엔진`으로 바꿀 수 있지만 페이지당 비용이 들고, 손글씨는 여전히 정확하지 않습니다.
- **비용**: 학생 30명 × 서술형 3문항 = 90회 호출이며, Haiku 4.5 기준 수십 원 수준입니다. 첨부 파일이 크면 더 듭니다.
- **오류가 나면**: 감독 화면에 `오류 n`으로 표시됩니다. 키·모델 ID·인터넷 연결을 확인한 뒤 [AI 채점 실행]을 다시 누르면 실패한 답안만 다시 채점합니다.

## 8. 알아두기

- 서버(교사 프로그램)가 꺼져도 학생 답안은 실시간 파일로 기록되어, 다시 켜면 **시험이 이어집니다.**
- 같은 접속 코드로 두 자리에서 로그인하면 먼저 접속한 쪽이 끊깁니다.
- 데이터 저장 위치: `%APPDATA%\class-server-teacher\classdata\` (명단·과제·제출물·시험 결과·첨부 답안 전부)
- 학생 클라이언트의 클립보드 감시(시험 중)는 사전에 학생들에게 고지하세요.
- 학생 화면은 **[과제] / [시험]** 두 탭으로 나뉘며, 위쪽 "연결됨" 표시를 누르면 서버 주소·응답 속도·마지막 답안 저장 시각 등 연결 상태를 볼 수 있습니다. 답안 칸 크기는 학생이 바꿀 수 없습니다.
- 교사가 시험을 종료하면 전체화면 잠금 여부와 관계없이 학생 화면이 곧바로 종료 안내로 바뀝니다.
- AI 채점을 쓰는 경우, 학생 답안이 외부 서비스(OpenRouter 및 선택한 모델 제공사)로 전송된다는 점을 학교 방침에 따라 안내하세요. 개인정보(이름·번호)는 전송되지 않습니다.
