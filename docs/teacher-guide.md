# 교사용 사용설명서

## 1. 시작하기

1. 교사 PC에서 **교실 평가 시스템 (교사용)** 을 실행합니다.
2. 처음 실행 시 Windows 방화벽 창이 뜨면 **"개인 네트워크"에 체크하고 [액세스 허용]** 을 누르세요. (이걸 놓치면 학생이 접속할 수 없습니다 → [network-setup.md](network-setup.md))
3. 화면 상단에 **학생 접속 주소**(예: `192.168.0.10:3690`)가 표시됩니다. 칠판에 적어주세요.

## 2. 학생 명단 등록

- **[학생 명단] 탭** → 직접 추가하거나, **CSV 불러오기**(형식: `번호,이름` — 엑셀에서 저장한 파일 그대로 가능)
- 학생마다 **접속 코드 6자리**가 자동 발급됩니다. **[접속코드표 다운로드]** 로 출력해서 나눠주세요.
- 코드가 유출되면 해당 학생의 **[재발급]** 을 누르면 됩니다.

## 3. 학생 접속

학생 PC에서 `ClassServer-학생용.exe` 실행 →
**[자동 찾기]** (또는 칠판의 주소 입력) → 자기 접속 코드 입력 → 접속.
현황판에서 접속 여부가 실시간으로 보입니다.

## 4. 과제 배부와 회수

1. **[과제] 탭** → 제목/설명 입력, 파일 첨부 → **[과제 생성]**
2. 목록에서 **[배부]** 를 누르면 학생 화면에 나타납니다.
3. 학생은 파일을 내려받아(바탕화면 `받은과제` 폴더) 작업 후 **[제출하기]** 로 올립니다.
4. **[제출 현황]** 에서 실시간 확인, **[제출물 전체 다운로드 (zip)]** 로 일괄 회수 — `01_김민준/보고서.hwp` 형태로 정리됩니다.

## 5. CBT 시험

1. 문제 만들기 — 두 가지 방법:
   - **직접 입력**: [시험] 탭 → **새 시험 만들기** → 객관식/단답형/서술형 문항 추가, 배점·정답 지정
   - **엑셀로 일괄 등록**: **[문제 양식(엑셀) 다운로드]** 로 양식을 받아 문제를 채운 뒤 **[엑셀로 문제 가져오기]** → 편집기에서 검토 후 저장
     - 양식 열: `유형(객관식/단답형/서술형) | 문제 | 배점 | 정답 | 보기1 ~ 보기10`
     - 객관식 정답 = 보기 번호(1~N), 단답형 정답 = 인정 답안(여러 개면 `;`로 구분), 서술형은 정답 비움
     - 잘못된 행은 행 번호와 함께 알려주고 건너뜁니다.
   - 문항 유형별 채점: **객관식·단답형은 자동 채점**(단답형은 공백·대소문자 무시), 서술형은 수동 채점
   - **문항 순서 섞기 / 선택지 순서 섞기**가 기본 켜짐 → 학생마다 문항 번호가 다르게 재구성되어 출제됩니다. (옆자리 훔쳐보기 방지)
2. **[시작]** → 시험 시간(분) 입력 → **전체화면 잠금 여부 선택** → 접속한 모든 학생 화면이 시험 모드로 전환됩니다.
   - 전체화면 잠금은 선택 사항입니다(기본 꺼짐). 잠금을 꺼도 붙여넣기 차단과 이탈 감지는 동일하게 작동합니다.
   - 학생 화면은 문제 영역과 **답안 표기란(OMR)** 이 분리되어 있어, 실제 CBT처럼 오른쪽 표기란에서 답을 고르거나 확인할 수 있습니다.
3. 감독 화면에서 학생별 **진행률 / 이탈 횟수 / 제출 여부**를 실시간 확인.
   - 학생이 다른 창으로 전환하면 즉시 표시됩니다. (⚠ Alt+Tab 자체를 막을 수는 없고, **감지·기록**됩니다)
   - 붙여넣기·복사 시도, 클립보드 변화도 모두 기록됩니다.
4. 시간이 끝나면 **자동 제출**됩니다. 먼저 끝낸 학생은 직접 제출할 수 있습니다.
5. 객관식·단답형은 **자동 채점**, 서술형은 **[답안/채점]** 버튼으로 확인 후 점수 입력.
   - 단답형은 같은 화면에서 **점수 정정**도 가능합니다. (오타 부분 인정 등 — 비우면 자동 채점으로 복귀)
6. **[결과 CSV 다운로드]** → 엑셀에서 바로 열립니다. (문항별 점수 + **문항별 정답률(%)** 요약 포함)
7. **성적 돌려주기**: 채점을 마친 뒤 감독 화면에서 **[성적 공개]** 를 누르면, 학생들이 홈 화면의 [시험 결과]에서
   본인 점수와 문항별 정오·정답을 확인할 수 있습니다. 언제든 **[성적 공개 취소]** 로 다시 감출 수 있습니다.
8. **시험 관리**:
   - **복제** — 같은 문제로 재시험을 보고 싶을 때. 새 초안이 만들어지며 기존 시험과 결과는 그대로 보존됩니다.
   - **삭제** — 초안·종료된 시험 삭제 가능(진행 중은 불가). 종료된 시험은 학생 응시 기록도 함께 삭제되니, 필요하면 결과 CSV를 먼저 내려받으세요.
   - **수정** — 초안 상태의 시험만 수정할 수 있습니다. 종료된 시험을 고쳐서 다시 보려면 [복제] 후 수정하세요.

## 6. 시험 중 학생 프로그램 잠금

- 시험 중 학생은 프로그램을 종료할 수 없습니다.
- 특정 학생만 풀어줘야 하면: **[도구] 탭 → 해제 코드 발급** → 코드를 불러주면 학생이 입력 후 종료 가능 (10분 유효, 1회용)
- 수업이 끝나면: **[전체 학생 잠금 해제]**

## 7. 알아두기

- 서버(교사 프로그램)가 꺼져도 학생 답안은 실시간 파일로 기록되어, 다시 켜면 **시험이 이어집니다.**
- 같은 접속 코드로 두 자리에서 로그인하면 먼저 접속한 쪽이 끊깁니다.
- 데이터 저장 위치: `%APPDATA%\class-server-teacher\classdata\` (명단·과제·제출물·시험 결과 전부)
- 학생 클라이언트의 클립보드 감시(시험 중)는 사전에 학생들에게 고지하세요.
